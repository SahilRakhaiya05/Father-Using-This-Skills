# Brief for the report writer

Read every notes file in the research folder (and an earlier report on the same topic if one is named), then
write ONE report that answers the user's full question.

## Structure
1. **Title** (short, specific)
2. **Bottom line** — the answer in 3–5 sentences, first.
3. **Key findings** — 4–8, each a clear claim with its evidence and source numbers.
4. **Detail** — one section per sub-question; prose first, tables for comparisons, a timeline for history.
5. **Where sources disagree / what's uncertain**
6. **What this means for you** — only if the user is deciding something.
7. **Sources** — renumber across all notes, de-duplicate, keep title, publisher, date, link.

## Rules
- Every factual claim traceable to a source; every number cited.
- Reconcile, don't stack: when notes conflict, say which you trust more and why.
- Plain language, short paragraphs, no filler, no claims the notes don't support.
- Save to the exact path you were given; reply with a 3-line summary.
